# 🌿 MindCare – Community Wellness & Habit Tracking Platform

MindCare is a modern web platform designed for daily habit formation, mood tracking, AI-powered journal sentiment analysis, and interactive behavioral analytics.

## ✨ Key Features

- 📊 **Interactive Overview Dashboard**: Quick mood check-ins (1-10 intensity slider), today's habit checklist, and daily mindful affirmations.
- 🗓️ **Habit Tracker & Matrix**: Weekly 7-day routine tracker with streak metrics, category filtering (*Mindfulness, Fitness, Learning, Self-Care, Nutrition*), and custom habit creator.
- 🧠 **AI Sentiment Analysis Reflection Journal**: Real-time client-side NLP engine calculating positivity scores (-10 to +10), emotion tags, sentiment token extraction, and actionable AI advice.
- 📈 **Behavioral Analytics**: SVG mood trend graphs, emotional pattern distribution, habit compliance percentages, and data-driven self-improvement tips.
- 🤝 **Community Wellness Feed**: Anonymous community reflection sharing with interactive support reactions (*✨ Spark, 🌿 Peace, ❤️ Support, 💪 Strength*) and weekly wellness challenges.

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Building for Production

```bash
npm run build
```

The output bundle will be generated in the `dist/` directory.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Vanilla CSS (Glassmorphism, CSS Custom Tokens, Soothing Palette)
- **Icons**: Lucide React
- **NLP**: Custom lexicon & rule-based sentiment classifier
